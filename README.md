
# AI Learning Chatbot

An AI-powered learning assistant built with Google Gemini and Streamlit.

## Features
- Ask AI questions in English, Urdu, and Roman Urdu.
- Generate quizzes on different topics.
- Choose quiz difficulty and language.
- Automatically check student answers.
- Display marks, percentage, and explanations.

## Technologies
- Python
- Streamlit
- Google Gemini API

## Run locally
1. Install the requirements:
   pip install -r requirements.txt

2. Add your Gemini API key to Streamlit secrets.

3. Run the application:
   streamlit run app.py
